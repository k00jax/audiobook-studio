# My Audiobook Library

This folder is your **audiobook library**. Audiobook Studio watches it automatically.

## Recommended: use a cloud-synced folder

Store this library in **OneDrive**, **Google Drive**, or **Dropbox** so your MP3s are available on your phone and other devices. The app runs on your computer; your audio files sync through the cloud.

## Folder layout

```
My Audiobooks/                 ← this folder (WATCH_FOLDER)
  CLAUDE.md                    ← instructions for AI writing assistants
  My Novel/                    ← one book project
    ch01_opening.md
    ch02_the_journey.md
    AUDIO/                     ← dictated MP3s (created by the app)
    Notes/                     ← bookmarks (created by the app)
```

## Writing chapters

- Separate major sections with `---` on its own line
- Use `## Section Title` for headers within a chapter
- Name files consistently: `ch01_...`, `ch02_...`, etc.

## Getting started

1. Run **Audiobook Studio** and complete setup if prompted
2. Open your library in the app — projects appear as books
3. Select chapters and click **Dictate** to generate speech (free with Edge TTS)

See `CLAUDE.md` for full conventions when working with Claude or other AI assistants.
